## Sobre o Produto Mínimo Viável (MVP)

Esta aplicação web interativa valida a viabilidade técnica de uma plataforma de revisão voltada especificamente ao concurso de Agente de Tecnologia do Banco do Brasil, organizado pela Fundação Cesgranrio.[cite: 1] A arquitetura prioriza a simplicidade de navegação e eficiência de uso, com layout responsivo para computadores, tablets e smartphones.

### Funcionalidades Validadas no Protótipo:

* **Navegação Interativa:** Interatividade entre 42 slides sequenciais, organizados por capítulos temáticos (Busca, Ordenação, Estruturas Lineares, Árvores, Big-O).
* **Revisão Multimodal (Áudio/Podcast):** Playlist flutuante com 4 faixas musicais educativas (com letras na tela) e 1 episódio de podcast ("Podcast TI: Cesgranrio Edition" de 13:22 min).
* **Simulações e Motor de Quiz:** Simulações interativas passo a passo dos algoritmos e 11 quizzes interativos distribuídos entre os capítulos, com feedback imediato.
* **Radar Cesgranrio e Leitura de Código:** Seção dedicada a "bizus" e alertas sobre pegadinhas recorrentes da banca, além de trechos de código-fonte em Java comentados.

---

## Stack Tecnológica

* **Front-end:** HTML5, CSS3 e JavaScript (incluindo manipulação de canvas/DOM para as animações de algoritmos).
* **Hospedagem:** Implantação contínua na plataforma Vercel.
* **Próximas Iterações (Back-end e BD previstos):** Node.js com framework Express e banco de dados Firebase (Firestore) ou PostgreSQL.
