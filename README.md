## Sobre o Produto Mínimo Viável (MVP)

Esta aplicação web interativa valida a viabilidade técnica de uma plataforma de revisão voltada especificamente ao concurso de Agente de Tecnologia do Banco do Brasil, organizado pela Fundação Cesgranrio.[cite: 1] A arquitetura prioriza a simplicidade de navegação e eficiência de uso, com layout responsivo para computadores, tablets e smartphones.[cite: 1]

### Funcionalidades Validadas no Protótipo:

* **Navegação Interativa:** Interatividade entre 42 slides sequenciais, organizados por capítulos temáticos (Busca, Ordenação, Estruturas Lineares, Árvores, Big-O).[cite: 1]
* **Revisão Multimodal (Áudio/Podcast):** Playlist flutuante com 4 faixas musicais educativas (com letras na tela) e 1 episódio de podcast ("Podcast TI: Cesgranrio Edition" de 13:22 min).[cite: 1]
* **Simulações e Motor de Quiz:** Simulações interativas passo a passo dos algoritmos e 11 quizzes interativos distribuídos entre os capítulos, com feedback imediato.[cite: 1]
* **Radar Cesgranrio e Leitura de Código:** Seção dedicada a "bizus" e alertas sobre pegadinhas recorrentes da banca, além de trechos de código-fonte em Java comentados.[cite: 1]

## Stack Tecnológica

* **Front-end:** HTML5, CSS3 e JavaScript (incluindo manipulação de canvas/DOM para as animações de algoritmos).[cite: 1]
* **Hospedagem:** Implantação contínua na plataforma Vercel.[cite: 1]
* **Próximas Iterações (Back-end e BD previstos):** Node.js com framework Express e banco de dados Firebase (Firestore) ou PostgreSQL.[cite: 1]
